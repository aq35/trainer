黒い画面（ターミナル）が初めての人が、**自分の作業を Git でコミットし、取り消し、ブランチで試し、コンフリクトを自分で直せる**ようになるまでの、全10回の教材です。

## この教材の約束

- **用語は、Git の公式の解説書（[Pro Git 日本語版](https://git-scm.com/book/ja/v2)）にそろえます。** 独自の呼び名は使いません。
- **コマンドを打つ画面には、根拠のリンクを付けます。** Git 本体の説明・Pro Git・GitHub Docs のどれかです。
- **画面に載せる出力は、実際に Git で打って得たものだけ**です（手で書き写していません）。どの版の Git で打ったかも書いてあります。
- **練習は、この教材のリポジトリをフォークして行います。** 第2回で、あなたの GitHub のアカウントにコピーします。
- **パソコンの準備の前に、ブラウザだけでも試せます。** 第2〜10回のコマンドの画面で「▶ ブラウザの中の擬似ターミナルで打ってみる」を押すと、その場でコマンドを打てます。返ってくるのは、本物の Git で打って記録した出力です（ダミーの環境なので、あなたのパソコンや GitHub は変わりません）。

## いまどこまで進んだか

進み具合は、このブラウザに自動で保存されます。途中でやめても、続きから再開できます。
