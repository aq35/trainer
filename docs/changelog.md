## 2026-08-03 — 「コピー」ボタンが、34か所で途中までしかコピーしていなかった（v1.13）

**表示の崩れを探していて、もっと悪いものが出てきました。**

<div class="checkpoint">
<strong><code>git commit -m "…"</code> のコピーボタンを押すと、コピーされるのは <code>git commit -m </code> まででした。</strong><br>
——<b>ダブルクォート（"）から先が、まるごと消えていました。</b>
</div>

**原因**は1行です。コピーの値を HTML の属性（`data-copy="…"`）に入れているのに、**`"` だけエスケープしていませんでした。** 値の中の `"` が属性の閉じ記号として読まれ、そこで切れていたのです。

| どこ | 全体 | 実際にコピーされていた分 |
| --- | --- | --- |
| **6. はじめてのプログラム** のHTMLひな型 | 315字 | **27字**（`<!DOCTYPE html>` の途中） |
| **8. 世界に公開する** のHTMLひな型 | 553字 | **27字** |
| **19. グラフにする** のAIへの頼み文 | 348字 | **28字** |
| **16. MCP × GitHub** の接続コマンド | 115字 | 83字（**トークンの指定が消える**） |
| `git commit -m "…"` （全回に散在） | — | **`git commit -m ` で終わり** |
| `git config --global user.name "…"` | 38字 | 30字 |

**全部で34か所、22回のうち17回**が影響していました。

<div class="note">
<b>「コマンドをコピーして貼る」は、この教材の中心の操作です。</b>そこが壊れていました。<br>
しかも<b>画面には正しく表示されていた</b>ので、見た目では気づけません。<b>押して、貼って、はじめて分かる種類の不具合</b>でした。
</div>

**確認** — 全22回の**コピーボタン192個すべて**について、「画面の表示」と「コピーされる値」が一致することを確かめました（**不一致 0**）。代表4件は実際にクリップボードから読み出して、全文が入ることを確認しています。

<div class="note">
<b>あわせて表示の検査もしました。</b>全22回・全画面を、パソコン幅（1280px）とスマホ幅（375px）の両方で走査 —— <b>横スクロール・はみ出し・画像切れ・ボタンの重なりは0件</b>でした。トップページとコマンド練習も同様です。
