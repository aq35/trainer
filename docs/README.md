## 進め方の約束

- **急がなくて大丈夫**です。
- わからない言葉が出てきたら [用語集](glossary.md) を見てください。載っていなければ、そのまま **Claude に聞く**のが一番早いです。
- どこかで**15分以上詰まったら、一人で抱えずに連絡**してください。**詰まるのは普通のこと**で、あなたの能力とは関係ありません。

## 困ったときに開くもの

- [Step 0: ターミナル入門](step0-terminal.md) — 黒い画面が初めてで不安な人向け。この先コマンドを打つ場面があるので、**先に読んでおくと楽になります**

## サポートする人向け

- [環境構築でやっていること](step1-setup.md) — 何を入れているか、つまずきの原因と対応表
- 受講者が詰まったとき、各ナビの「うまくいきません」から**今の状況をコピーするボタン**が使えます。「どのステップで、何ができなかったか、何分経ったか」が文章になります。
- 同じステップに15分以上とどまっている受講者には、ナビ側から**自動で声かけ**が表示されます。
- ⚠️ **連絡先の設定が必要です。** `docs/config.js` にサポート窓口（担当者名・チャンネル・URL）を記入してください。未設定のままだと、案内に「連絡先が未設定です」と表示されます。
