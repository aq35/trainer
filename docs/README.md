## いまどこまで進んだか

上から順に進めてください。**進み具合は自動で記録される**ので、途中でやめても続きから再開できます。

<div id="map">読み込み中…</div>

<div class="note">
<b>1〜8で 15〜25時間、9〜11でさらに 10〜20時間、12〜16の「修行」で 8〜12時間、17〜22で 12〜17時間</b>ほどです（10番目は自分のテーマなので、かける時間は自由です）。<br>
<b>17〜22は「動くものを、良くする」段階です。</b>遅さを測って直す、繰り返しを道具に変える、数字をグラフにする、フロントかバックかを切り分ける、<b>推測せずに機械から事実を取り出す</b>、保存先を選び直す——<b>22番だけは任意</b>（Node.js が要ります）。<br>
<b>12〜16は、案件に入る前の仕上げです。</b>ここまでで「作る」は一周しているので、残りは<b>人と組む部分</b>——レビューする側、曖昧な報告を追う、知らないコードに入る、人を頼る——と、<b>道具を持たせる部分</b>（MCP）です。<br>
<b>1日で終わるものではありません。</b>数週間かけて進める人がほとんどなので、遅いと感じる必要はまったくありません。<b>1つ終わるごとに休憩してください。</b>
</div>

<div class="note">
⏳ <b>先に、時間の話を正直にしておきます。</b><br>
上の<b>50〜75時間は「土台」</b>です。そのうえに、<b>案件に合わせて逆算する期間（およそ1か月）</b>が乗ります。<b>この2つで、ようやく1セット</b>です。<br>
<b>地図を全部埋めた時点で「準備できた」と思わないでください。</b>——そこからが本番です。→ <a href="#/plan">案件まで1か月。何をする？</a>
</div>

<div class="note">
🧱 <b>ただし、勘違いしないでください。土台が、いちばん大事です。</b><br>
<b>土台は腐りません。</b>git も、レビューも、不具合の切り分けも、報告のしかたも、<b>10年後もほぼ同じ</b>です。<br>
一方、案件ごとに必要になる技術（フレームワーク、クラウド、言語）は<b>3年で入れ替わります</b>。<br>
<b>だから先に土台をやります。</b>——逆算の1か月は「土台のうえに、その案件ぶんを足す」時間であって、<b>土台の代わりではありません</b>（<a href="#/path">くわしく</a>）。
</div>

## 練習用のリポジトリ

**9番目の「仕事の一周」から、最後まで**使い続けます。**他人が書いた小さなアプリ**で、**14個の依頼**が入っています。

| 何が入っているか | 使うステップ |
| --- | --- |
| 不具合の修正（原因の見つけ方が毎回違う5つ） | 9 / 13 |
| あいまいな依頼／コンフリクト | 9 |
| テストを書く・整理する・レビューする | 9 |
| 遅さを直す・計測を道具にする・グラフにする | 17 / 18 / 19 |
| フロントかバックかの切り分け／壊れた地点の特定 | 20 / 21 |
| データベースに差し替える（任意） | 22 |

- <img class="ti" width="26" height="26" src="media/icon-github.svg" alt="">[aq35/trainer-practice](https://github.com/aq35/trainer-practice) — **インストール不要**。プルリクエストを出すと、**自動でチェックが走ります**

<div class="note">
⚙️ <b>チェックしているのは、AIではありません。</b>（Copilot でもありません）<br>
<b>GitHub Actions</b> が、リポジトリの中に入っている小さなスクリプト（<code>.github/scripts/grade.mjs</code>）を動かしているだけです。<b>中身は全部読めますし、書き換えられます。</b><br>
見ているのは<b>機械的に決まることだけ</b>——テストが通ったか、PRの説明が書いてあるか、鍵らしき文字列が混ざっていないか、テストの数が減っていないか。<br>
だから<b>判定はいつも同じで、0円で、何回出しても構いません。</b>AIによるレビューは、これとは別に<b>あなた自身のAI</b>で行います（そのやり方も研修の中でやります）。
</div>

## 進め方の約束

- **急がなくて大丈夫**です。
- **文法を覚える研修ではありません。** コードを一字一句暗記する必要はなく、**読んで、おかしければ断れる**ようになれば十分です。書くのはAIと一緒でかまいません。これは手抜きではなく、**いまの現場のやり方そのもの**です。
- わからない言葉が出てきたら [用語集](glossary.md) を見てください。載っていなければ、そのまま **Claude に聞く**のが一番早いです。
- どこかで**15分以上詰まったら、一人で抱えずに連絡**してください。**詰まるのは普通のこと**で、あなたの能力とは関係ありません。
