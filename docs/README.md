## 進め方の約束

- **急がなくて大丈夫**です。
- **文法を覚える研修ではありません。** コードを一字一句暗記する必要はなく、**読んで、おかしければ断れる**ようになれば十分です。書くのはAIと一緒でかまいません。これは手抜きではなく、**いまの現場のやり方そのもの**です。
- わからない言葉が出てきたら [用語集](glossary.md) を見てください。載っていなければ、そのまま **Claude に聞く**のが一番早いです。
- どこかで**15分以上詰まったら、一人で抱えずに連絡**してください。**詰まるのは普通のこと**で、あなたの能力とは関係ありません。
