## なぜ無料なのか

未経験からエンジニアを目指す人が、**最初の一歩で数十万円を払う必要はない**と考えているからです。

実際、この研修で使うものは次のとおりです。

| 使うもの | 費用 |
| --- | --- |
| VS Code | 無料 |
| Git | 無料 |
| GitHub（個人利用） | 無料 |
| GitHub Pages での公開 | 無料 |
| この教材 | 無料 |
| Claude Code の利用 | **研修の担当者が用意します**（あなたの負担はありません） |

<div class="note">
つまり、<b>あなたが払うものは0円</b>です。もし「この研修を受けるために支払いが必要」と言われたら、それはこの教材とは無関係のものです。
</div>

## この教材が、しないこと

<div class="qa">
<div class="q">「3か月で年収〇〇万円」みたいな話は？</div>
<div class="a"><b>しません。</b>そういう約束は誰にもできません。ここで身につくのは「開発の現場に入って、最初の1か月を生き延びる力」です。それ以上でも以下でもありません。</div>
</div>

- **就職・転職を保証しません。** できるのは、必要な土台を渡すところまでです
- **他の商品を売りません。** 途中で有料コースに誘導することはありません
- **個人情報を集めません。** 進捗は**あなたのブラウザの中**にだけ保存されます。こちらのサーバーには何も送られません
- **急かしません。** 期限も、脱落もありません。1か月かかっても構いません

## 高いお金を払う前に、確かめてほしいこと

学習にお金を払うこと自体は、悪いことではありません。**良い教材や、良い指導者には価値があります。** ただ、未経験の段階では判断材料が少なく、それにつけこむものも存在します。

**支払う前に、次の点を確認してください。**

<div class="qa">
<div class="q">① 何を教えてくれるかが、具体的に書いてありますか</div>
<div class="a">「AIを使いこなす」「未経験からプロへ」だけでは、中身が分かりません。<b>目次や、実際に作るものが公開されているか</b>を見てください。この教材で言えば、<a href="/">トップページ</a>にステップが全部並んでいます。</div>
</div>

<div class="qa">
<div class="q">② 無料で確かめられる部分がありますか</div>
<div class="a">中身を見せずに全額前払いを求めるものは、慎重に判断してください。</div>
</div>

<div class="qa">
<div class="q">③ 「保証」の条件が書いてありますか</div>
<div class="a">就職保証・返金保証をうたう場合、<b>条件が細かく決まっていることが普通</b>です。条件が読めない、質問しても曖昧なら、いったん止まってください。</div>
