## 一人で始める人の、3つの道

<div class="note">
どれを選んでも、<b>学べる内容は同じ</b>です。違うのは「AIをどこで動かすか」だけです。<b>迷ったら A から始めてください。</b>後からいつでも変えられます。
</div>

### A. 0円で進む（おすすめ・まずはこれ）

**ブラウザで無料の Claude を使い、コードは自分でコピー＆ペーストします。**

- お金は**1円もかかりません**
- VS Code、Git、GitHub、公開まで、**すべて本編どおり**に進められます
- 違いは「AIがファイルを直接書き換えてくれない」ことだけ。**自分で貼る**ぶん、実は差分を読む力がつきます
- 無料枠には**1日に使える量の上限**があります。止まったら時間をおけばまた使えます

<div class="checkpoint">
<strong>本気で学ぶのに、この道で十分です。</strong> 「無料だから劣る」ということはありません。実際、コードを自分の手で貼る作業は、初心者にとってむしろ良い訓練になります。
</div>

### B. Claude の有料プランを使う（Claude Code をそのまま使う）

**Claude Code を VS Code の中でそのまま使えます。**（本編と同じ体験）

- Claude の有料プランに加入し、拡張機能で**サインイン**すれば使えます
- 月額料金がかかります。**プランの種類と金額は変わることがある**ので、[claude.com](https://claude.com) で最新を確認してください
- 環境構築ナビでは、これが**①（標準）**の道です。「**Claude Code にサインインします**」のステップをやり、「（②の人だけ）会社のキーでつなぐ設定をします」は**飛ばして**ください
- APIキーを自分で書く作業はありません。**サインインするだけ**です

### C. API のクレジットを買う（従量課金）

**使ったぶんだけ支払う方式**です。この場合も環境構築ナビの**①**の道を進み、サインインのときに **Anthropic Console** のほうを選びます。少額から始められますが、**残高の管理が必要**なので、初心者には A か B をおすすめします。

<div class="note">
<b>Claude Code は、無料では使えません。</b>B か C のどちらかの登録が必要です。<b>お金をかけたくない場合は A</b> を選んでください。学べる内容は同じです。
</div>

<div class="note">
<b>お金を払うかどうかは、最後まで終わってから決めても遅くありません。</b> まず A で一周してみて、「毎日使いたい」と思ったときに B を検討するのが、いちばん損のない順番です。
</div>

## A（0円ルート）の進め方

やることは2つだけです。**①環境構築で5ステップ飛ばす ②AIはブラウザで使う。**

### ① 準備（10分）

1. [claude.ai](https://claude.ai) を開き、**無料アカウント**を作ります（メールアドレスだけで作れます）
2. [環境構築ナビ](setup.html ':ignore target=_blank') を開き、**次の順で進めます**

| 環境構築ナビのステップ | 0円ルートでは |
| --- | --- |
| 始め方が3通りあります | **読む**（このページの「A」を選びます） |
| VS Code を入れます | **やる** |
| 作業用のフォルダを開きます | **やる** |
| ターミナルを出します | **やる** |
| Git を入れます | **やる** |
| Claude Code を VS Code に追加します | **飛ばす** |
| Claude Code にサインインします | **飛ばす** |
| （②の人だけ）会社のキーでつなぐ設定をします | **飛ばす** |
| VS Code を閉じて、開き直します | **飛ばす** |
| AIに話しかけてみます | **飛ばす**（代わりにブラウザで話しかけてみてください） |

飛ばすときは、画面の「**できました**」を押して先に進んで構いません。**進捗の記録が壊れることはありません。**

### ② これ以降のステップの読み替え

本編で「Claude Code に頼む」と出てきたら、**ブラウザの Claude に頼み、返ってきたものを自分で貼る**と読み替えてください。

| 本編の指示 | 0円ルートでのやり方 |
| --- | --- |
| Claude Code に「〇〇して」と頼む | ブラウザの Claude に同じ文章を送る |
| ファイルを見てもらう | **ファイルの中身をコピーして、会話に貼る**（先に「これが今のファイルです」と書く） |
| AIの提案を承認する | 返ってきたコードを**自分で VS Code に貼って保存**する |
| AIの提案を断る | **貼らない。それだけです** |
| 変更内容（差分）を確認する | 貼ったあとに、ターミナルで `git diff` と打つ |
| 変更を取り消す | ターミナルで `git restore .` と打つ |

<div class="checkpoint">
<strong>「読んで、納得したら採用する」という一番大事な部分は、まったく同じです。</strong> むしろ自分の手で貼るぶん、何が変わったかを意識しやすくなります。
</div>

## 各ステップで、具体的にどう変わるか

<details>
<summary><b>「AIと一緒に直す」の回</b>（ここだけ手順が大きく変わります）</summary>

このステップは Claude Code の**承認・拒否ボタン**を前提にしています。0円ルートでは、次のように置き換えてください。

1. **「毎回確認してもらう設定」** → 飛ばします。ブラウザ版は、そもそも勝手にファイルを書き換えません（**最初から安全**です）
2. **「小さな仕事を頼む」** → ブラウザに、こう送ります

   > 次の内容の hello.txt があります。最後に「今日は差分の読み方を覚えました」という行を1行だけ足した全文を出してください。他は変えないでください。
   >
   > （ここに hello.txt の中身を貼る）

3. **「わざと断ってみる」** → 返ってきた内容を見て、**貼らずに閉じます**。これが「断る」です
4. **「今度は承認する」** → 気に入ったら VS Code に貼って保存 → ターミナルで `git diff` を打ち、**増えた行が1行だけか**を自分の目で確かめます
5. **「自分の名前で記録する」** → 本編と同じ。`git add` と `git commit` を打ちます

<div class="note">
<b>ここでの学びは「差分を読んで、自分で決める」ことです。</b> ボタンがあるかどうかは、本質ではありません。
</div>
</details>

<details>
<summary><b>「自分のテーマで回す」の回</b></summary>

`CLAUDE.md`・`@`・`/clear` は Claude Code の機能ですが、**同じことがブラウザでもできます。**

| 本編 | 0円ルート |
| --- | --- |
| `CLAUDE.md` に前提を書く | 同じ内容をメモ帳に書いておき、**会話の最初に毎回貼る**（コピペ1回で済みます） |
| `@ファイル名` で指定する | **そのファイルの中身を貼る**。「これが今の index.html です」と添える |
| `/clear` で会話を切る | **新しい会話を始める**（左上の「新しいチャット」） |
| Plan モードで計画を見る | 頼み文の先頭に「**実装はせず、まず手順だけ教えてください**」と書く |

やっていることは同じです。**手作業が1つ増えるだけ**だと思ってください。
</details>

<details>
<summary><b>そのほかのステップ</b></summary>

**すべて本編どおりで進められます。** git も GitHub も開発者ツールも公開も、AIとは関係のない部分です。

エラーが出たときは、**そのエラー文をコピーしてブラウザの Claude に貼り**、「これはどういう意味？どうすればいい？」と聞いてください。本編で案内しているやり方と同じです。
</details>

## よくある質問

<div class="qa">
<div class="q">無料枠を使い切ってしまいました</div>
<div class="a">しばらく時間をおけば、また使えるようになります。<b>その間は、AIを使わないステップを進めてください</b>（git、GitHub、公開まわりはAIなしで進みます）。長いコードを何度も貼ると早く使い切るので、<b>必要な部分だけを貼る</b>と長持ちします。</div>
</div>

<div class="qa">
<div class="q">途中から有料プランに変えられますか？</div>
<div class="a"><b>いつでも変えられます。</b>作ったファイルも記録もそのまま残ります。環境構築ナビに戻って、飛ばした2ステップ（<b>Claude Code を VS Code に追加します</b> と <b>Claude Code にサインインします</b>）をやるだけです。</div>
</div>

<div class="qa">
<div class="q">「進捗をコピーする」ボタンは押さなくていい？</div>
<div class="a">一人で進めているなら、<b>押す必要はありません</b>（送る相手がいないので）。<b>記録は自分のブラウザに残っている</b>ので、進み具合は自分で確認できます。<br>ときどきコピーして、自分用のメモに貼っておくと、あとで振り返るときに便利です。</div>
</div>

<div class="qa">
<div class="q">一人だと、詰まったとき誰にも聞けません</div>
<div class="a">まず<b>AIに聞いてください</b>。「何をしたか・何が出たか・どうなってほしいか」の3つを書けば、ほとんどは解けます。それでもだめなら、<a href="https://github.com/aq35/trainer/discussions" target="_blank" rel="noopener">この教材の Discussions</a> に書いてください。<b>同じところで詰まった人の助けにもなります。</b></div>
</div>

<div class="qa">
<div class="q">結局、本当に0円ですか？</div>
<div class="a"><b>0円です。</b>VS Code・Git・GitHub・GitHub Pages・ブラウザ版 Claude の無料枠、すべて無料です。この教材も無料です（<a href="#/about">理由</a>）。<b>お金が必要になる場面はありません。</b></div>
</div>
